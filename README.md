# Ocean Logistics Control Tower

Virginia Transformer Corp ocean freight dashboard: analysis, detailed report, performance charts, and an admin upload portal.

## Run locally

```bash
pip install -r requirements.txt
python run.py
```

Open [http://127.0.0.1:8050](http://127.0.0.1:8050). Admin upload is at `/admin`.

Shipment Excel/JSON files stay on the server and are not stored in this repository. Upload a DSR workbook in Admin to load data.
