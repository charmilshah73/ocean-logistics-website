# Ocean Logistics Control Tower

Virginia Transformer Corp ocean freight dashboard: analysis, detailed report, performance charts, and an admin upload portal.

**Live site:** [https://charmilshah73.github.io/ocean-logistics-website/](https://charmilshah73.github.io/ocean-logistics-website/)  
**Source:** [https://github.com/charmilshah73/ocean-logistics-website](https://github.com/charmilshah73/ocean-logistics-website)

The published site is the UI. Shipment Excel/JSON stays local and is not in GitHub. Run locally and upload a DSR workbook in Admin to load live data.

## Run locally

```bash
pip install -r requirements.txt
python run.py
```

Open [http://127.0.0.1:8050](http://127.0.0.1:8050). Admin upload is at `/admin`.
